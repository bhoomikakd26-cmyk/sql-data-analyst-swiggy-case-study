# 📊 Swiggy Business Analytics – SQL Case Study

SQL Business Analytics Case Study completed as part of the DevTown SQL for Data Analysts – 5-Day Bootcamp (2026).

## 📌 Project Overview

This project is a SQL-based business analytics case study focused on analyzing customer, restaurant, and order data from a Swiggy-like food delivery platform.

The project was completed as part of the **DevTown SQL for Data Analysts – 5-Day Bootcamp (2026)**.

The objective was to use SQL to answer business questions and generate insights related to revenue, customers, restaurants, cuisines, delivery partners, order performance, and business growth.

## 🗃️ Database Structure

The project uses three main tables:

### Customers
Contains customer information such as:
- Customer ID
- Customer Name
- City
- Membership

### Restaurants
Contains restaurant information such as:
- Restaurant ID
- Restaurant Name
- Cuisine
- City
- Rating

### Orders
Contains order transaction information such as:
- Order ID
- Customer ID
- Restaurant ID
- Order Amount
- Delivery Partner
- Order Date
- Order Status

## ❓ Business Questions

The SQL analysis answers 20 business questions, including:

1. Total number of orders
2. Total revenue
3. Average order value
4. Top 5 highest-value orders
5. City generating the highest revenue
6. Restaurant generating the highest revenue
7. Most popular cuisine
8. Delivery partner with the highest number of successful deliveries
9. Customers spending more than the average order value
10. Second-highest order amount
11. Restaurant with the highest rating
12. Cities generating revenue above ₹2,000
13. Customers who never placed an order
14. Restaurants that never received orders
15. Detailed customer order information
16. Order categorization using CASE WHEN
17. Customer ranking based on total spending
18. Order ranking using ROW_NUMBER()
19. Restaurant ranking using DENSE_RANK()
20. Final business report and recommendations
